# 帕斯卡 ↔ 布列安桑 · 几何定理系列 01（竖屏 48 秒）

**一个证明，白送一个定理。** 圆内接六边形三组对边的交点共线（帕斯卡定理，1639），把“点”和“线”互换，就得到圆外切六边形三条对角线共点（布列安桑定理，1806）。片子先把两个定理“玩”给你看，再用**升维 → 降维打击**一眼看穿为什么：把外切六边形的边一上一下翘到三维，它们全躺在一张单叶双曲面（广州塔“小蛮腰”）上，三条空间对角线只能交于一点；再从正上方打光，**影子**交于一点——这就是布列安桑定理；最后对偶回去，帕斯卡定理也成立。

- **成片规格**：1080×1920 竖屏 · 30 fps · 48.45 s · H.264（CRF 17）+ AAC 256k · 响度 −13 LUFS / 真峰值 ≤ −1 dBTP
- **面向**：高中生也能看懂的科普——每个结论都配一个直观画面：“圆锥曲线都是圆的影子”（点光源投影）、“直线的影子还是直线”、“从正上方打光看影子”（平行投影）
- **节奏**：按音乐实测的节拍网格（1 拍 = 0.737 s ≈ 81.4 BPM，首拍 0.489 s）排布，所有变形 / 文字 / 音效都落在拍或半拍上；画面始终在动（拖动、变形、运镜），场景之间全部由形状变形衔接，没有硬切
- **几何严格正确**：每一帧都从 6 个角度从头精确计算（齐次坐标求交、极点 / 极线、3-D 抬升），`tools/verify_geometry.mjs` 对全片 1455 帧逐帧审计，所有关联误差 ≤ 2×10⁻¹³（相对半径）
- **动效风格**（取自 [mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15)）
  - **线条风** `02-line-art`：午夜蓝底 + 香槟金线、发光笔尖、描线生长（draw-on）、镜头缓推缓拉
  - **手绘风** `05-cel-boil`：线条 2 帧一抖（line boil）、胶片颗粒、cel 冲击特效（冲击波环、放射线、火花、闪白）
  - **形状即叙事** `08-morph`：圆 → 椭圆 → 抛物线 → 双曲线 → 圆；帕斯卡的“红线 + 三个交点”直接**变形**成布列安桑的“三条对角线 + 红点”；平面六边形“升”成三维双曲面，再被“拍扁”回平面
- **立体光影（升维段 22.6–36 s）**：双曲面是半透明玻璃质感——3 档 cel 明暗 + 菲涅尔边缘光 + 高光带，直纹母线分前后层、按深度排序；杆件是带明暗条纹的 cel 圆管；地面有柔和的投影和光池；“从正上方打光”时一束顶光照下来，地上的影子被重新上色，正好就是平面里的布列安桑图形

## 数学（片中每一句话的依据）

- **帕斯卡定理**：圆锥曲线的内接六边形，三组对边（所在直线）的交点共线。帕斯卡 1639 年 16 岁时发现，1640 年发表于《圆锥曲线论》（*Essay pour les coniques*）。
- **圆锥曲线都是圆的“影子”**：椭圆、抛物线、双曲线都是圆在点光源下的中心投影；投影把直线变成直线、交点变成交点，所以“共线”被保留——这就是“换成别的圆锥曲线，照样共线”的直观原因。
- **对偶**：关于圆的极点 / 极线对应把点 ↔ 线、共线 ↔ 共点、内接 ↔ 外切。帕斯卡定理的对偶就是**布列安桑定理**：圆锥曲线的外切六边形，三条对角线共点。布列安桑（C. J. Brianchon，1783–1864）1806 年还是巴黎综合理工学院的学生时在 *Journal de l’École Polytechnique* 上发表，比帕斯卡晚 167 年。布列安桑点正是帕斯卡线的极点（片中红线 ⇄ 红点同步移动）。
- **升维证明（布列安桑定理）**：把外切六边形的 6 条切线交替地以斜率 +λ、−λ 抬出平面（顶点高度 = ±λ × 切线长）。从一个顶点出发的两条切线长相等，所以相邻两条斜边仍然相交；6 条斜边都是单叶双曲面 x² + y² − z²/λ² = R² 的直母线，相对的两边属于不同的母线族 ⇒ 共面 ⇒ 三条空间对角线两两共面 ⇒ 两两相交；三条线又不共面 ⇒ 只能交于同一点 Q。从正上方打光（竖直投影），顶点 V 的影子就是平面顶点 W，于是三条影子对角线交于 Q 的影子 B——布列安桑定理证毕。再对偶一次，帕斯卡定理也成立。
- **全片逐帧审计**（`node tools/verify_geometry.mjs`）：帕斯卡共线、布列安桑共点、六边都与圆相切、B 是帕斯卡线的极点、斜边在双曲面上、斜边过切点、空间对角线过 Q、Q 的影子是 B、V 的影子是 W，最大相对误差 2.2×10⁻¹³。

## 声音设计（`tools/sfx.py`）

- **音乐**：用户提供的配乐，从 0 s 开始，截断到片长，47.75 → 48.45 s 淡出；除了整体音量归一和降维打击处 3 dB 的短暂闪避，不做任何改动。
- **音效只做点缀**：全片只有 10 个“恍然大悟”的瞬间各来一下“叮叮叮”或“咚”（见上表最后一列），其余时间只有音乐——音乐自己有旋律，不和它抢。
- “叮”是程序合成的钟片音，音高取自音乐的 **D# 小调**，并跟随这首曲子本身约 **+39 音分**的调音偏移（实测整首比 A=440 高了将近四分之一个半音；不跟随的话“叮”会听起来走调）。开场“叮叮叮”（A#5–C#6–D#6）和“帕斯卡定理也成立”时的“叮叮叮”是同一个动机，前后呼应。
- “咚”是调音过的鼓（圆膜非谐泛音 + 鼓皮 + 鼓槌），并联一路谐波激励，手机外放这种没有低音的喇叭也听得到；降维打击是更大的 D#2 “咚！”。
- 每个音效的响度都相对“同一时刻音乐的 K 加权响度”自动校准；母带：音乐 −14 LUFS → 叠加音效 → 轻房间混响 → 前瞻真峰值限幅，整体 −13 LUFS，wav 真峰值 −2 dBTP（AAC 编码后 ≤ −1 dBTP）。

## 生成

```bash
cd pascal-brianchon-video
npm i playwright && npx playwright install chromium     # 另需 ffmpeg、python3（numpy / scipy / fonttools / pillow）
# 字体（均为 SIL OFL 1.1，不随仓库分发）：
#   Noto Serif CJK SC Black / Bold（.ttc）→ 默认读 /usr/share/fonts/google-noto-cjk，可用 NOTO_DIR 指定
#   LXGW WenKai Medium → fonts/LXGWWenKai-Medium.ttf（https://github.com/lxgw/LxgwWenKai/releases）
python3 tools/glyphs.py                    # → assets/glyphs.json（改了任何文案都要重跑）
cp /path/to/music.wav audio/music.wav      # 配乐（用户提供，不随仓库分发）
python3 tools/sfx.py                       # → out/audio_master.wav
node tools/verify_geometry.mjs             # 几何逐帧审计
node render.mjs stills 3.44,12.29,35.89 --scale 0.5   # 抽帧检查 → out/stills/
node render.mjs video --workers 2          # → out/video.mp4（≈1455 帧）
```
