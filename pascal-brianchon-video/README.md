# 帕斯卡 ↔ 布列安桑 · 几何定理系列 01（竖屏 70 秒 · v2）

**一个证明，白送一个定理。** 圆内接六边形三组对边的交点共线（帕斯卡定理，1639），把“点”和“线”互换，就得到圆外切六边形三条对角线共点（布列安桑定理，1806）。片子先把两个定理**一步一步“摆”给你看**，再用**升维 → 降维打击**看穿为什么：把外切六边形的边一上一下翘到三维，它们全躺在一张单叶双曲面（广州塔“小蛮腰”）上，三条空间对角线只能交于一点；再从正上方打光，**影子**交于一点——这就是布列安桑定理；最后对偶回去，帕斯卡定理也成立。

- **成片规格**：1080×1920 竖屏 · 30 fps · 69.9 s · H.264（CRF 17）+ AAC 256k · 响度 −13 LUFS / 真峰值 ≤ −1 dBTP
- **面向**：高中生一定能看懂——每一步只讲一件事：先给大字结论，再用一句大白话说“为什么”，画面上同步演示；复杂的地方拆开、放慢
- **节奏**：按音乐实测的节拍网格（1 拍 = 0.737 s ≈ 81.4 BPM，首拍 0.489 s）排布，冲击 / 音效都落在拍上；三维证明段整体放慢（剧情拍 48–68 映射到音乐拍 48–80），“降维打击”仍然砸在小节线上
- **几何严格正确**：每一帧都从 6 个角度从头精确计算（齐次坐标求交、极点 / 极线、3-D 抬升），`tools/verify_geometry.mjs` 对全片 2097 帧逐帧审计，所有关联误差 ≤ 7×10⁻¹³（相对半径，平面部分 ≤ 3×10⁻¹⁵）
- **动效风格**（取自 [mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15)）
  - **线条风** `02-line-art`：午夜蓝底 + 香槟金线、发光笔尖、描线生长（draw-on）、一笔描边、镜头缓推缓拉
  - **手绘风** `05-cel-boil`：线条 2 帧一抖（line boil）、胶片颗粒、cel 冲击特效（冲击波环、放射线、火花、闪白、震屏）
  - **形状即叙事** `08-morph`：圆上的点“长”成切线；三个交点各自“飞”进一条对角线；红线“缩”成红点；平面六边形“升”成三维双曲面，再被“拍扁”回影子；最后整套对偶变形倒放回帕斯卡
- **立体光影（三维证明段 35.9–59.5 s）**：双曲面是半透明玻璃质感——3 档 cel 明暗 + 菲涅尔边缘光 + 高光带，直纹母线分前后层、按深度排序；杆件是带明暗条纹的 cel 圆管；顶灯在地面打出光池和影子；“从正上方打光”时一束顶光照下来，竖直光线把每个顶点、把 Q 点落到地面，地上的影子正好就是平面里的布列安桑图形

## v2 改了什么（对照 v1）

1. **先把定理讲明白、展示清楚**：6 个点带编号 1–6 依次冒出 → 一笔连成六边形 → 三组对边逐组上色（面对面的两条边同色）→ 逐组延长、交点逐个冒出 → 红线“啪”地切过三点。每一步一个大字标题 + 一句白话说明。
2. **对偶一步一步搭**：点 → 切线（逐条长出）→ 外切六边形（6 个顶点逐个弹出并编号、白光沿 6 条边描一圈）→ 交点 → 连接相对顶点（1–4、2–5、3–6）的对角线（逐条飞入）→ 红线缩成红点。
3. **对偶字典**：点 ⇄ 线、交点 ⇄ 连线、共线 ⇄ 共点，逐行弹出。
4. **三维证明拆成编号的 5 步**（顶部进度条 ①–⑤），从 v1 的约 14 秒放慢到约 24 秒；“每两条都在同一个平面里”时，把那张平面实际亮出来、曲面退后。
5. 删掉了 v1 的“换成别的圆锥曲线”支线，把时间留给主线；片长 48 s → 70 s。

## 数学（片中每一句话的依据）

- **帕斯卡定理**：圆（更一般地，任意圆锥曲线）的内接六边形，三组对边（所在直线）的交点共线。帕斯卡 1639 年 16 岁时发现，1640 年发表于《圆锥曲线论》（*Essay pour les coniques*）。
- **对偶**：关于圆的极点 / 极线把点 ↔ 线、交点 ↔ 连线、共线 ↔ 共点、内接 ↔ 外切。圆上的点对应过它的切线；内接六边形的边 A_kA_{k+1} 对应外切六边形的顶点 W_k（两条切线的交点）；两条对边的交点 X_k 对应连接相对顶点 W_k、W_{k+3} 的对角线（它正是 X_k 的极线）。帕斯卡定理的对偶就是**布列安桑定理**：外切六边形的三条对角线共点。布列安桑（C. J. Brianchon，1783–1864）1806 年还是巴黎综合理工学院的学生时发表，布列安桑点正是帕斯卡线的极点（片中红线 ⇄ 红点同步移动）。
- **升维证明（布列安桑定理）**：把外切六边形的 6 条切线交替地以斜率 +λ、−λ 抬出平面（顶点高度 = ±λ × 切线长）。从一个顶点出发的两段切线一样长（切线长定理），所以相邻两条斜边在顶点处一样高、仍然相交；6 条斜边都是单叶双曲面 x² + y² − z²/λ² = R² 的直母线，相对的两边一上一下、属于不同的母线族，所以相交 ⇒ 它们的 4 个端点共面 ⇒ 三条空间对角线两两共面、两两相交；三条线又不共面（否则 6 条斜边都在一个平面里）⇒ 只能交于同一点 Q（若三个交点不同，它们围成的三角形会把三条线放进同一个平面）。从正上方打光（竖直投影），顶点 V 的影子就是平面顶点 W，于是三条影子对角线交于 Q 的影子 B——布列安桑定理证毕。再对偶一次，帕斯卡定理也成立。
- **全片逐帧审计**（`node tools/verify_geometry.mjs`）：帕斯卡共线、布列安桑共点、六边都与圆相切、B 是帕斯卡线的极点、斜边在双曲面上、斜边过切点、空间对角线过 Q、Q 的影子是 B、V 的影子是 W。
- **构图**：交点要全部落在竖屏里，六个点就必须“一边密、一边疏”（三组对边与平行的偏离角 δ₁、δ₂ = δ₁ + δ₃、δ₃ 都要够大，可以证明最小间隔 ≤ 60° − ⅔·min|δ|），所以外切六边形有 4 个顶点贴着圆——片中给这 6 个顶点编号、逐个弹出并描边，保证一眼数得出“六”边形（`tools/search_home.mjs` 搜索构图）。

## 声音设计（`tools/sfx.py`）

- **音乐**：用户提供的配乐，从 0 s 开始，截断到片长，69.2 → 69.9 s 淡出；除了整体音量归一和降维打击处 3 dB 的短暂闪避，不做任何改动。
- **音效只做点缀**：全片只有 8 个“恍然大悟”的瞬间各来一下“叮叮叮”或“咚”（见上表最后一列），其余时间只有音乐——音乐自己有旋律，不和它抢。
- “叮”是程序合成的钟片音，音高取自音乐的 **D# 小调**，并跟随这首曲子本身约 **+39 音分**的调音偏移（实测整首比 A=440 高了将近四分之一个半音；不跟随的话“叮”会听起来走调）。三个交点冒出时的“叮叮叮”（A#5–C#6–D#6）和“帕斯卡定理也成立”时的“叮叮叮”是同一个动机，前后呼应。
- “咚”是调音过的鼓（圆膜非谐泛音 + 鼓皮 + 鼓槌），并联一路谐波激励，手机外放也听得到；降维打击是更大的 D#2 “咚！”。
- 每个音效的响度都相对“同一时刻音乐的 K 加权响度”自动校准；母带：音乐 −14 LUFS → 叠加音效 → 轻房间混响 → 前瞻真峰值限幅，整体 −13 LUFS，wav 真峰值 −2 dBTP（AAC 编码后 ≤ −1 dBTP）。

## 生成

```bash
cd pascal-brianchon-video
npm i playwright && npx playwright install chromium     # 另需 ffmpeg、python3（numpy / scipy / fonttools / pillow）
# 字体（均为 SIL OFL 1.1，不随仓库分发）：
#   Noto Serif CJK SC Black / Bold（.ttc）→ 默认读 /usr/share/fonts/google-noto-cjk，可用 NOTO_DIR 指定
#   LXGW WenKai Medium → fonts/LXGWWenKai-Medium.ttf（https://github.com/lxgw/LxgwWenKai/releases）
python3 tools/glyphs.py                    # → assets/glyphs.json（改了任何文案都要重跑）
cp /path/to/music.wav audio/music.wav      # 配乐（用户提供，不随仓库分发）
python3 tools/sfx.py                       # → out/audio_master.wav
node tools/verify_geometry.mjs             # 几何逐帧审计
node render.mjs stills 9.34,24.09,59.48 --scale 0.5   # 抽帧检查 → out/stills/
node render.mjs video --workers 2          # → out/video.mp4（2097 帧）
```
