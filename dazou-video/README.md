# 大走理论 · 走路科普竖屏短视频（≈47 秒）

“弱者躺平，强者大走”——继“大水理论”“大睡理论”之后，用一部不到 50 秒的竖屏动画，把“大走理论”讲成一条有依据的走路科普：拒绝躺平久坐，每天多走路，用轻运动维持代谢与精神状态。

- **成片规格**：1080×1920 竖屏 · 30 fps · 47.6 s · H.264（CRF 17）+ AAC 256k · 响度 −12 LUFS / 真峰值 ≤ −1 dBTP
- **时长策略**：上一批视频平均播放 17–18 s，本片压到 1 分钟内；**每 1 小节（≈2.13 s）至少一次大的形状变化**，片中每个场景都由上一个场景的图形“变”出来，没有硬切；17.1 s（观众最容易划走的位置）正好是音乐 DROP + 全片第一个大反转
- **钩子**：第 0 帧就有大字“弱者躺平”；1.7 s 小人连同沙发被压成一条平线，音乐“磁带急停”只剩心电监护“滴——”；2.2 s 心电尖峰跳起变成小人，音乐原位恢复，“强者大走”砸出来
- **音乐**：用户提供的配乐，从 0 s 开始，截断到片长，47.0 → 47.6 s 淡出。BPM 实测 112.9，首拍 0.083 s，所有变形 / 文字 / 音效都落在小节、拍或十六分音符上（`tools/beat_grid.py`）
- **动效风格**（取自 [mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15)）
  - **线条风** `02-line-art`：主角“线条小人”就是 5 根线 + 1 个圆；上一个图形的线就是下一个图形的线（平线 → 心电尖峰 → 小人 → 墨笔字 → 椅子 → 时间轴 → 血糖曲线 → 地面……）
  - **手绘风** `05-cel-boil`：墨线 2 帧一抖（line boil，15 fps 的手绘节奏）、色块错位上色、纸纹、手绘速度线 / 烟团 / 星芒
  - **形状即叙事** `08-morph`：形状本身讲故事——“躺平”真的躺成一条**平**线；小人张开四肢变成“**大**”字、迈开大步变成“**走**”字；“大”的三笔变成椅子；一脚把血糖“高山”踩扁
- **画面里不出现“开智”**（片头角标为“走路小科普”）

## v2 视觉升级（声音设计保持不变，只补了几处与新画面对应的小音效）

- **修 bug**：第 ③ 条贴士里小人站在灯泡正下方，看起来像“灯泡长在头上”；结尾灯泡缩成小人的头也是同一个问题。现在 ③ 改成一圈脚印从灯泡下方走过，结尾灯泡沉到地平线、变成**日出**，小人在旁边重新画出来、迎着太阳走
- **夜景钩子**：0–2.2 s 整个房间是深蓝夜色，只有手机屏幕的蓝光照着瘫在沙发上的人，点赞爱心一拍一个往外冒；被压成平线后变成发绿光的心电监护线
- **光爆揭幕**：2.2 s 心电尖峰跳起的同时，黑夜从尖峰处被一圈橙黄冲击波撕开，纸面世界“亮”出来
- **镜头**：每小节缓慢推近、下一次变形时回弹；强拍轻踢；DROP / 高潮 / 盖章等落点按命中点做冲击推镜 + 阻尼旋转
- **彩色背景块**：每个主角图形背后都有一块随小节变形的 riso 色块（圆 → 圆角方 → 星爆 → 有机团块……），带半调网点投影，跟着节拍呼吸
- **冲击帧**：DROP（17.1 s）和高潮（34.1 s）各 2 帧反色冲击帧，随后旋转放射光芒 + 彩纸爆开
- **大数字砸入**：↓58%、↓47% 放大并从镜头前“砸”到纸面（过冲回弹 + 二次震屏）
- **结尾**：暖色日出 + 天空放射光，最后一拍两侧礼花筒彩纸

## 事实依据

- **久坐打断实验**：每坐 30 分钟起来轻松走 5 分钟，与连续坐 8 小时相比，大餐后的血糖峰值降低 58%，血压降低 4–5 mmHg（Diaz et al., *Medicine & Science in Sports & Exercise*, 2023；哥伦比亚大学）
- **每日步数**：与每天 2000 步相比，每天 7000 步与全因死亡风险低 47%、痴呆风险低 38%、抑郁症状风险低 22% 相关（Ding et al., *The Lancet Public Health*, 2025，57 项研究的剂量-反应荟萃分析）
- **走路与创造力**：边走边想时，创造性产出平均提升约 60%（Oppezzo & Schwartz, *J. Exp. Psychol.: Learning, Memory, and Cognition*, 2014；斯坦福大学）
- **国内指南**：《中国居民膳食指南（2022）》准则二——每周至少 5 天中等强度身体活动、累计 150 分钟以上；主动身体活动最好每天 6000 步；减少久坐时间，每小时起来动一动

## 声音设计（`tools/sfx.py`）

- 全部音效程序合成（numpy / scipy），约 270 个事件，按节拍网格放置：文字弹出“啵”、脚步、毛笔“唰”、印章、钟表“咔嗒”、电量下降、计步“嗒嗒嗒”、灯泡“叮”、开关“咔哒”+ 上行琶音、两次大脚“咚”等；v2 只新增了光爆 / 彩纸 / 日出的轻闪光、③ 的一串脚印“嗒嗒”和结尾礼花筒“啵”
- 每个音效的响度相对“同一时刻音乐的 K 加权响度”自动校准；DROP（17.1 s）和高潮（34.1 s）处音乐短暂闪避 4.5 dB 给大脚让路
- 唯一改动音乐本身的地方：1.68 s 的“磁带急停”（播放速度 1→0，音高下坠），2.21 s（第 2 小节强拍）按原时间位置恢复，节拍网格不受影响
- 母带：音乐先统一到 −14 LUFS → 加音效 → 轻房间混响 → 前瞻真峰值限幅，整体 −12 LUFS，wav 真峰值 −2 dBTP（AAC 编码后 ≤ −1 dBTP）

## 目录

```
dazou-video/
├── index.html          # 浏览器预览（拖动时间轴 / 播放）
├── render.mjs          # Playwright 逐帧渲染 → ffmpeg；自动混入 out/audio_master.wav
├── js/
│   ├── film.js         # 全片分镜：每个场景一个函数，时间全部写成 B[k] / bt(n)
│   ├── guy.js          # 线条小人：姿势、反解、可变形笔画、墨笔“大”“走”
│   ├── shapes.js       # 沙发、手机、桌椅、时钟、电池、手表、大脑、灯泡、开关、脚丫……及其可变形轮廓
│   ├── engine.js       # 抖线、墨线、样条、轮廓变形（morph）、缓动
│   ├── text.js         # 字形轮廓文字（弹入 / 飞出 / 描边）
│   ├── fx.js           # 星芒、速度线、烟团、闪光
│   └── fx2.js          # v2：变形色块 + 半调投影、放射光芒、彩纸、爱心、暗角、反色冲击帧
├── tools/
│   ├── sfx.py          # 音效合成 + 混音母带
│   ├── beat_grid.py    # 测 BPM / 首拍
│   ├── glyphs.py       # 从字体提取用到的字形 → assets/glyphs.json
│   ├── gen_paper.py    # 纸纹
│   └── fetch_assets.sh # 下载字体 / 纸张贴图
└── assets/             # glyphs.json + 纸纹
```

## 生成

```bash
cd dazou-video
npm i && npx playwright install chromium
bash tools/fetch_assets.sh                 # 字体 + 纸纹（OFL / CC0）
cp /path/to/music.mp3 audio/music.mp3     # 配乐（不随仓库分发）
python3 tools/sfx.py                       # → out/audio_master.wav
node render.mjs stills 0,2.2,17.1 --scale 0.5   # 抽帧检查
node render.mjs video --workers 3          # → out/video.mp4
```

改了任何文案后需要重新跑 `python3 tools/glyphs.py`。
