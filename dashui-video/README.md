# 大水理论 · 喝水科普竖屏短视频（45 秒）

“弱者喝饮料，强者喝大水”——用一部 45 秒的竖屏动画，把爆火的“大水理论”讲成一条有依据的喝水科普。

- **成片规格**：1080×1920 竖屏 · 30 fps · 45.2 s · H.264 + AAC
- **音乐**：用户提供的配乐，从 0 s 开始，截断到 45.2 s（结尾 0.8 s 淡出）。BPM 实测 112.9，首拍 0.082 s，所有切换都落在小节/拍点上
- **动效风格**（取自 [mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15)）
  - **手绘风** `05-cel-boil`：墨线逐帧“抖动”（2 帧一画），色块与线稿错位上色，纸张纹理
  - **线条风** `02-line-art`：问号、人体轮廓、箭头、进度条刻度都是“一笔画出”
  - **形状即叙事** `08-morph`：问号 → 水面线 → 涟漪 → 人体 → 大脑 → 干瘪水滴 → 洪水 → 水杯 → 大瓶 → 进度条 → 甜饮料 → 方糖 → 水滴 → 满瓶 → 警示三角 → 大瓶，平均每 2 小节（≈4.3 s）至少一次大的形状变化
- 画面全部由代码逐帧绘制（Canvas2D），每一帧都是时间 t 的纯函数，可重复渲染

## 事实依据

- 《中国居民膳食指南（2022）》：成年男性每天喝水 1700 mL、女性 1500 mL；少量多次，每次 1 杯（约 200 mL）；不用饮料代替白水；添加糖每天不超过 50 g，最好控制在 25 g 以下
- 成年人身体约 60% 是水；轻度脱水（失水约体重的 1%–2%）就会影响注意力、记忆力等认知表现（Popkin et al., *Nutrition Reviews* 2010）；感到口渴时身体通常已经开始缺水
- 常见 500 mL 含糖饮料约含 50 g 糖（约 10 g/100 mL），按每块方糖约 4 g 计 ≈ 12 块
- 短时间内大量饮水可能导致低钠血症（“水中毒”）

## 声音

- 配乐：用户提供的音乐，从 0 s 开始，截断到 45.2 s，44.4 s 起淡出。
- 音效：`tools/sfx.py` 全部程序合成（无采样），共 167 个音效点，与画面事件逐一对齐（文字弹出“啵”、水滴、撞击、洪水、方糖落堆、进度条、咕咚喝水、警告、打卡“叮”等）。
- 每个音效按同一时刻音乐的 K 加权响度自动校准，大撞击时音乐自动闪避 4 dB 左右。
- 母带：BS.1770 积分响度 −12 LUFS，4× 过采样前瞻限幅，真峰值 ≤ −1.5 dBTP（wav）。

## 如何渲染

依赖：Node 18+（`npm i`，即 playwright）、Chromium、ffmpeg、Python 3（`pip install fonttools pillow numpy scipy`）

```bash
bash tools/fetch_assets.sh            # 字体 + 纸张贴图 → assets/（glyphs.json 已提交，可跳过字体）
cp /path/to/music.mp3 audio/music.mp3 # 配乐（未提交到仓库）
python3 tools/sfx.py                  # → out/audio_master.wav（配乐截断到 45.2 s + 音效）
node render.mjs stills 2.2,17.1,34.3  # 预览单帧 → out/stills/
node render.mjs video --workers 2     # → out/video.mp4
```

Chromium 路径可用环境变量 `CHROME_PATH` 指定。
