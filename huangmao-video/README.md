# 黄毛理论 · 黄毛小科普（v2）

竖屏科普短视频：55 秒讲清“黄毛理论”——**黄毛不在头上，在心里**：不迎合、不内耗、说干就干，而且只要愿意，谁都能当。

- **规格**：1080×1920，30 fps，55.35 s，H.264 + AAC 48 kHz；响度 −12 LUFS，真峰值 ≤ −1.5 dBTP
- **时长策略**：账号历史平均观看 17–18 s，所以前 17 s 把“是什么”讲完（钩子 → 片名 → 三个特征 → 词源 → 小时候），17.1 s 的 DROP 正好落在金句“黄毛不在头上，在心里”；全片每个镜头 1 小节（2.13 s）左右，画面主体约每 2 s 换一次形状 / 构图
- **钩子（0–2.2 s）**：“为什么老实人，总输给黄毛？”——斜切分屏 + VS 贴纸，小红心犹豫一下，拐弯飞到黄毛身上“+1”
- **音乐**：用户提供的配乐，从 0 s 开始，截断到片长，54.55 s 起与画面一起淡出。BPM 实测 112.9，首拍 0.082 s；全片 26 小节，镜头、字幕、转场、动作和音效都落在小节 / 拍 / 八分音符上；B8（17.09 s）DROP、B16（34.09 s）高潮
- **画面风格**（v2 全部重画，参考 [mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15) 的 `01-flat-vector` 扁平矢量与 `18-hanazi` 综艺花字）
  - **扁平矢量角色**：老实人（眼镜、蓝衬衫）、黄毛（尖刺黄发、红夹克），以及一群不同年龄、头发全黑或花白的普通人；挤压拉伸、弹性落地、眨眼、口型、正侧面
  - **吉祥物“黄毛心”**：一颗长着黄毛的爱心。DROP 时冲破方框从胸口跳出来，之后变成每个普通人胸前的小徽章——“黄毛”从发型变成一种状态，形状本身就是叙事
  - **综艺花字**：白色粗描边 + 彩色外描边 + 硬投影，关键词换色放大，逐字弹性弹出；高潮用金黄渐变的三层大花字
  - **转场 5 种**：圆形扩散 iris、斜切 diag、百叶 slats、推移 push、爱心扩散 heart；DROP 与高潮用硬切
- **画面合规**：画面和字幕不出现“街溜子、随心所欲、勇敢、真诚、真心、不被社会规训、做自己”，不出现“开智”，不点名任何网红或真实人物（v1 的真实人物故事已换成四个普通人的小场景）；这些意思只用行为表达：敢举手、自己去追、直接说、说“不”、我试试

## 事实依据

- 黄毛理论的修正版定义（“黄毛的本质就是不迎合、不跪舔、不内耗，代表着自信自爱和精神自由”）与“高富帅……黄毛只要愿意，谁都能当”：虎嗅《薄肌和大水理论崛起后，中文互联网的“大理论时代”开始了》 https://www.huxiu.com/article/4897592.html （片中只做转述，不点名）
- “黄毛”的词典义：黄发，借指年幼的人，如“黄毛丫头”“黄毛小子” https://www.zhongwen.cn/cidian/huangmao
- 时间越久，人越后悔“没做”的事：Gilovich, T., & Medvec, V. H. (1995). The experience of regret: What, when, and why. *Psychological Review*, 102(2), 379–395. https://psycnet.apa.org/record/1995-24085-001 ；2023 年的公开重复实验得到同样的时间模式 https://pmc.ncbi.nlm.nih.gov/articles/PMC10282588 。片中曲线标注“示意”，只表达趋势
- 调研全过程见 [RESEARCH.md](RESEARCH.md)

## 声音设计

- 全部音效由 `tools/sfx.py` 用 numpy / scipy 程序合成（326 个事件），不使用任何采样
- 字幕弹出的“啵”、转场的“嗖”由 `tools/export_cues.mjs` 直接从 `js/film.js` 导出时间点，改了画面音效自动跟上；其余动作音效按 `bb(小节, 拍)` 写在逐小节的音效表里，和 `js/s1.js`–`s3.js` 的动画时间一一对应
- **“叮”的上行动机**：胸口的黄毛心每亮一次，都是同一个“叮”，一次比一次高——DROP C6 → 想法 E♭6 → 机会 F6 → 喜欢 G6 → 滑板 B♭6 → 推门 C7（C 小调五声音阶），把几个小故事串成一条往上走的旋律
- 场景音效：喷漆 / 滚筒“刷黑”、失落的弱音小号“哇哇哇——”、纸卷“沙沙”、雨声与车声、钟表狂转、录像带倒带、摔跤、撕日历、发送消息、礼花
- 混音：每个音效按同一时刻音乐的 K 加权响度自动校准；DROP / 高潮处音乐闪避 4.5 dB 让冲击声透出来；母带 −12 LUFS、限幅 −2 dBTP（AAC 编码后约 −1.6 dBTP）

## 生成

```bash
cd huangmao-video
npm i && npx playwright install chromium
pip3 install numpy scipy fonttools
bash tools/fetch_assets.sh            # 下载字体并子集化 → assets/fonts/
# 把配乐放到 audio/music.mp3
python3 tools/sfx.py                  # 音效 + 混音 + 母带 → out/audio_master.wav
node render.mjs video --workers 2     # 逐帧渲染 → out/video.mp4（约 4–5 分钟）
node render.mjs stills 1.3,17.4,34.6  # 抽帧预览 → out/stills/
```

预览：用任意静态服务器打开 `index.html`，在控制台调用 `window.renderAt(t)` 即可查看任意时刻的画面。
