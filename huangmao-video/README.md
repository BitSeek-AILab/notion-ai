# 黄毛理论 · 竖屏科普短视频（≈53 秒）

“为什么老实人，总输给黄毛？”——继“大水理论”“大睡理论”“大走理论”之后，用一部 53 秒的竖屏动画科普“黄毛理论”，讲清楚**为什么要成为心里有火的“黄毛”**：网上说的“黄毛”赢，赢的从来不是头发，而是一种状态——**不迎合、不内耗、说干就干**。片子先把这个梗讲回它本来的意思（“黄毛丫头 / 黄毛小子”＝小孩，每个人小时候都是黄毛），再用真实故事和一条心理学研究说明：这撮“黄毛”在心里，只要愿意，谁都能当。

- **成片规格**：1080×1920 竖屏 · 30 fps · 53.2 s · H.264（CRF 17）+ AAC 256k · 响度 −12 LUFS / 真峰值 ≤ −1 dBTP
- **时长策略**：上一批视频平均播放 17–18 s，本片压到 1 分钟内；**每 1 小节（≈2.13 s）至少一次大的形状变化**，每个场景都由上一个场景的图形“变”出来，没有硬切；17.1 s（观众最容易划走的位置）正好是音乐 DROP：2 帧反色冲击帧 + 方框炸碎 + 火苗冲天
- **钩子**：第 0 帧就是大字“为什么老实人，总输给黄毛？”；一排方块头老实人每拍齐刷刷鞠躬，第 4 拍中间那个不弯腰，头顶“噗”地窜出一撮黄火苗
- **音乐**：用户提供的配乐，从 0 s 开始，截断到片长，52.4 → 53.2 s 与画面一起淡出。BPM 实测 112.9，首拍 0.082 s；所有变形 / 文字 / 音效都落在小节、拍、八分或十六分音符上（`tools/beat_grid.py`、`tools/analyze_music.py`）。画面“一拍二”（15 fps 手绘节奏）且以拍点为中心量化，每个落点与鼓点误差在 ±1 帧内
- **动效风格**（取自 [mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15)）
  - **线条风** `02-line-art`：主角“线条小人”是几根线 + 一个圆；上一个图形的线就是下一个图形的线
  - **手绘风** `05-cel-boil`：墨线 2 帧一抖（line boil）、色块错位上色、纸纹、半调网点、手绘速度线 / 烟团 / 星芒
  - **形状即叙事** `08-morph`：一撮黄毛 → 火苗 → 箭 → 路 → 小孩 → 火柱 → 船头 → 雨线 → 旧摩托 → 赛车 → 车轮 → 购物车 → 三把火合成一把 → 手掌 → “不” → 火柴 → 烧掉“我不配” → 两扇门 → 手机 → 箭头 → 片名
- **视觉语法：方块 vs 火苗**——方块头 / 方框 / 格子＝迎合、标准答案、被框住（灰、墨黑）；火苗＝黄毛状态，**全片唯一的亮黄色只给“黄毛”**，从一小撮一路长成冲天火柱、一群人胸口的火、观众手机里的火，最后收拢成片名
- **画面合规**：画面里不出现“开智”（角标为“黄毛小科普”）；不出现“街溜子、随心所欲、勇敢、真诚、真心、不被社会规训、做自己”等词；不点名任何网红；两位真实人物只讲故事、不出名字（画面里只写“19 岁修车学徒”“开超市的老板”“修车学徒出身的冠军老板”）

## 事实依据

- **“黄毛理论”的来龙去脉**：起初是网络上的调侃，后被社区修正为“黄毛的本质就是不迎合、不跪舔、不内耗”，“谁都能当”——本片采用这一版（虎嗅《薄肌和大水理论崛起后，中文互联网的“大理论时代”开始了》 https://www.huxiu.com/article/4897592.html ）
- **“黄毛”的本义**：黄发，借指年幼的人，如“黄毛丫头”“黄毛小子”（ https://www.zhongwen.cn/cidian/huangmao ）
- **修车学徒出身的冠军老板**（张雪，张雪机车创始人）：14 岁辍学当修车学徒；2006 年 19 岁时冒雨骑行 100 多公里追电视台摄制组，求一个上节目的机会；2026 年 3 月，张雪机车在 WSBK 世界超级摩托车锦标赛葡萄牙站 WorldSSP 组别双回合夺冠。原话：“年轻的时候没有去做，到老了肯定会后悔。年轻的时候做了，就算到老了，失败了，也不会后悔。”——B20 / B21 的文案即据此改写（新华网 https://www.news.cn/20260403/f792cf0b093d4785913849b90988d4f5/c.html ；21 世纪经济报道 https://www.21jingji.com/article/20260413/herald/088049f4ea1da36ec8a889a3debb721e.html ）
- **开超市的老板**（于东来，胖东来创始人）：2024 年起给员工 10 天“不开心假”，管理层不能不批（界面新闻 https://www.jiemian.com/video/AGQCOQhvB2EBPlVl.html ）
- **“黄毛教父”杰克**：电影《泰坦尼克号》（1997）里的穷画家杰克，坐三等舱，站在船头喊“我是世界之王”；画面只用线条小人致敬，不使用电影画面
- **后悔研究**：短期内人更后悔“做了的错事”，时间拉长后，更后悔“没做的事”（Gilovich & Medvec, 1995, *Psychological Review* 102(2), 379–395 https://psycnet.apa.org/record/1995-24085-001 ；2023 年的公开重复实验得到同样的时间模式 https://pmc.ncbi.nlm.nih.gov/articles/PMC10282588 ）
- 完整调研笔记见 [`RESEARCH.md`](RESEARCH.md)；最初的分镜草案见 [`STORYBOARD.md`](STORYBOARD.md)

## 声音设计（`tools/sfx.py`）

- 全部音效程序合成（numpy / scipy，无第三方采样），280 个事件，与 `js/s1.js`–`s3.js` 的动画时间点一一对应：鞠躬“唰”、火苗“呼”、弹簧“嘣”、气泡“啵”、乱线拉直“嗖”、助跑脚步 + 落地、墨刷“唰”、方框吱呀 + 蓄力、DROP 冲击 + 碎裂 + 火柱、海浪海风、雨声 + 雷声、旧摩托突突 → 赛车轰鸣、年份翻牌“咔嗒”、礼花筒、印章、车轮滚动、红笔打叉、骰子落台、火苗越闪越快、火柴“嚓”、纸烧着的噼啪、门吱呀、拐杖倒地、手机提示音、点赞“叮”、打字“嗒”、片名合拢的长“呼——”等
- 每个音效的响度相对“同一时刻音乐的 K 加权响度”自动校准；DROP（17.1 s）和高潮（34.1 s）处音乐短暂闪避 4.5 dB，雷声、印章、“不”、“嚓”、门被烧开、观众点燃、片名等落点小幅闪避
- 母带：音乐先统一到 −14 LUFS → 加音效 → 轻房间混响 → 前瞻真峰值限幅，整体 −12 LUFS，wav 真峰值 −2 dBTP（AAC 编码后 ≤ −1 dBTP）

## 生成

```bash
cd huangmao-video
npm i && npx playwright install chromium
pip3 install numpy scipy
bash tools/fetch_assets.sh                 # 字体 + 纸纹（OFL / CC0）+ 字形
cp /path/to/music.mp3 audio/music.mp3     # 配乐（不随仓库分发）
python3 tools/sfx.py                       # → out/audio_master.wav
node render.mjs stills 0,2.2,17.1,34.1 --scale 0.5   # 抽帧检查 → out/stills/
node render.mjs video --workers 3          # → out/video.mp4
```

改了任何文案后需要重新跑 `python3 tools/glyphs.py`。
